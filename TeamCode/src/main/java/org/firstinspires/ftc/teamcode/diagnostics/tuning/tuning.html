Shots and disturbances

With a wheel in VEL mode and inside its band for 0.3 s (badge armed), any drop out of the band is logged: dip depth, time to the bottom, and time until it is back in the band — the time the shooter is not ready after a shot. Kick is a synthetic disturbance (motor output cut for a few ms); it is repeatable but is not a real ball, so accept gains on real shots.

Turrets

The turrets are positional servos, so there is no PID to tune — only the mapping from angle to servo position that turret.java uses: pos = center ± deg / (servoRange × grB / grA). Find center (turret straight ahead), check reversed (+deg must turn the way the code expects), then verify the ratio by pointing at ±90° and measuring. Wrong ratio → aim error grows with angle.

Gate and scoopula

Both are currently 0 / 0 in shipped code (gate.openPos/closePos, scoopula.scoopPos/unscoopPos). Move the servo until it is where it belongs, then mark it.

Labelled samples → thresholds

Hold each piece where the sensor sees it during intake and capture ~40 reads. Do RED, BLUE, EMPTY (nothing in the intake) and every other thing the sensor might see (the other game piece, a piece half-in, field tiles). Vary position between captures. The suggestion maximises correct calls over all samples using the exact intake.dominant() rule.
